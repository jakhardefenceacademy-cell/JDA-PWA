## फोन में चलाने का तरीका
1. इस folder की सभी files GitHub repository के `main` branch के root में upload करें।
2. GitHub → Settings → Pages → Deploy from branch → `main` → `/ (root)` चुनें।
3. Pages का HTTPS link Chrome में खोलें।
4. Chrome menu → **Add to Home screen / Install app** दबाएँ।
5. App standalone mode में खुलेगा।
